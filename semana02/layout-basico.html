Arrependimento

O arrependimento é uma parte essencial da preparação para voltar à presença de Deus. Lembre-se de que o Senhor amorosamente concede misericórdia àqueles que se esforçam para se arrepender mesmo quando têm dificuldade para vencer certos pecados.
